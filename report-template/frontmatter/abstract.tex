\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This document is a fully populated demonstration of a modular engineering report template.
It illustrates configurable metadata, an optional cover logo, consistent running headers,
front matter, a single report-body menu, mathematical notation, theorem-style environments,
figures, subfigures, tables, code listings, robust missing-figure handling, appendices, and an
IEEE-style bibliography. The fictitious case study considers a four-channel smart sensor array
that estimates the direction of a narrowband source and reports system-health indicators to an
edge controller. Representative equations and numerical values are included only to demonstrate
formatting and document organization. Users should replace the sample material with verified
project-specific analysis, simulation results, measurements, and references.
